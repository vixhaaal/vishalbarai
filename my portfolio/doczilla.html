Doczilla

Selected work · PDF toolkit

Doczilla is a browser-based toolkit for common PDF tasks. I built it to bring document tools together in one clear, practical interface.

What it does

Merge and split PDFs, rotate pages, or turn images into PDFs. It includes previews, drag-and-drop, file validation, page ranges, and downloadable results.

Search, categories, favorites, and recently used tools help people find the feature they need.

  • PDF previews and browser-side file handling
  • Merge, split, rotate, and image-to-PDF tools
  • Search, categories, favorites, and recent tools

Built with

JavaScript, HTML, and CSS, with pdf-lib, PDF.js, and JSZip. Deployed on Vercel.
